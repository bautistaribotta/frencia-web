Tarjeta de vidrio sobre el Fondo: agrupa contenido relacionado.

```jsx
<Card variant="signal">
  <span className="frencia-label">En curso</span>
  <div style={{ font: 'var(--text-data)' }}>Push Pull Legs</div>
</Card>
```

Variantes: `default` (vidrio: `surface-card`, `glass-line`, blur y `shadow-glass`), `elevated` (`surface-card-elevated`, para lo que flota o se elige), `inset` (pozo de datos), `signal` (lo que está en curso) e `intensity` (esfuerzo, PR: en tinta, sin color). `hairline` sube el borde a `border-default`; `interactive` la vuelve tocable. Las variantes marcan estado, nunca decoran. `green` / `orange` siguen como alias.
