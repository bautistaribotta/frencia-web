Marca de estado compacta: tipo de serie, RIR o RPE, una sesión completada o un PR.

```jsx
<Badge tone="intensity-solid" icon="flame">Nuevo PR</Badge>
<Badge tone="signal">En curso</Badge>
<Badge>Completada</Badge>
```

Tonos: `neutral` (hairline, por defecto), `signal` (acero: lo que está en curso), `accent-solid` (tinta), `intensity` y `intensity-solid` (ámbar: esfuerzo y PR) y `danger`. Siempre en mayúsculas, sans al ancho semi. Un relleno sólido por pantalla como mucho; el resto, delineado. `green`, `green-solid`, `orange` y `orange-solid` siguen aceptados como alias.
