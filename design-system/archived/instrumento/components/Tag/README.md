Etiqueta para grupos musculares, categorías y filtros.

```jsx
<Tag dot>Pecho</Tag>
<Tag selectable selected>Empuje</Tag>
```

Hairline sin relleno, radio `radius-sm`. `selectable` para filtros tocables; `selected` la pinta de tinta. `dot` suma un punto antes del texto. Para marcas de estado en mayúsculas usá `Badge`.

En el catálogo, cada filtro lleva su conteo (`Pecho 27`) y hay uno activo por vez; tocar el activo vuelve a `Todos`. En una fila desplegada, el músculo objetivo va con `dot` y los que asisten, sin.
