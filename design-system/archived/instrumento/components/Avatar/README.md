Avatar circular: la foto o, sin foto, las iniciales en acero claro sobre acero profundo.

```jsx
<Avatar name="Liana Tudakova" size="md" ring />
```

Tamaños `xs` / `sm` / `md` / `lg`. Pasá `src` para la foto; si no, `name` arma las iniciales (`steel-300` sobre `steel-900`). `ring` suma un anillo de tinta (`accent`) separado del fondo por `bg-app`: marca al usuario activo, no decora.
